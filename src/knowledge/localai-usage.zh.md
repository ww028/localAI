# localAI 用户手册

localAI 是一个运行在 Chrome 浏览器内的本地优先 AI 助手。它主要用于日常对话、当前网页处理、本地知识库问答、个人记忆、文本处理、确定性计算和数据备份。localAI 会根据你的问题自动判断应该使用哪类能力，并优先使用你提供的本地资料和个人记忆。

localAI 不是互联网搜索工具，模型本身不会联网搜索实时网页、新闻、价格、百科或外部数据库。它的回答依据来自你当前输入的内容、当前网页正文、你导入的知识库、你保存的个人记忆、最近会话上下文以及内置使用说明，并在这些信息基础上进行推理和生成。如果你需要它分析外部资料，需要先把资料粘贴到输入框、导入知识库，或通过“当前网页”读取已打开页面。

## 快速开始

1. 打开 localAI 插件。
2. 在底部输入框输入问题或任务。
3. 点击发送按钮，或按 Enter 发送。
4. 如果需要在输入框内换行，按 Shift + Enter。
5. 等待回答生成完成后，可以在回答下方进行复制、重新回答或下载。

适合直接输入的问题包括：

- “帮我总结一下这段内容”
- “把下面内容翻译成英文”
- “把这些数据转成 JSON”
- “3 个方案按优先级排一下”
- “根据知识库回答这个项目的架构”
- “你记得我的偏好吗？”
- “这个 AI 怎么用？”

## 界面入口

localAI 常见入口包括：

- 输入框：输入问题、文本处理任务、计算任务、知识库问答或记忆查询。
- 发送按钮：提交当前输入内容。
- 当前网页：读取并处理当前浏览器页面。
- 知识库：导入、查看、管理本地资料。
- 个人记忆：查看、编辑、删除已保存的个人记忆。
- 历史对话：切换以前的会话，或新建对话。
- 设置：导出备份、导出通用数据、导入备份数据。

在全屏 Tab 模式下，左侧会显示历史对话侧边栏。侧边栏可以收起或展开，也可以搜索历史话题。侧边栏底部提供设置入口。

## 对话与回答操作

你可以把 localAI 当作普通 AI 助手使用，直接提出问题或描述任务。localAI 会根据问题自动选择合适的处理方式。

需要注意的是，localAI 不会主动联网检索信息。对于实时信息、互联网上的新内容、网页外部资料或你没有提供过的事实，localAI 不能保证知道最新答案。要让回答基于指定材料，需要把材料提供给 localAI，例如粘贴文本、导入知识库或打开网页后使用“当前网页”功能。

回答生成后，回答下方可能出现这些操作：

- 复制：复制当前回答文本。
- 重新回答：基于同一个用户问题重新生成回答，并替换当前回答。
- 下载为 Word：把当前回答导出为 `.doc` 文件，保留基础 Markdown 样式。
- 引用来源：如果回答使用了知识库或个人记忆，来源会以标签形式显示在回答下方。点击来源标签可以查看对应片段。

如果回答来自本地知识库，正文中可能出现 `[1]` 这样的引用编号；编号对应回答下方的来源标签。个人记忆通常不会在正文中显示编号。

## 当前网页功能

“当前网页”用于读取当前浏览器标签页的页面内容，并让 localAI 基于网页正文完成任务。

可用操作包括：

- 总结网页：提炼页面主题、核心观点和重要信息。
- 询问网页：围绕当前页面提问，localAI 只根据页面正文回答。
- 提取待办：从页面内容中提取行动项、负责人、时间点或后续任务。
- 整理笔记：把页面内容整理成结构化笔记，便于复用和回顾。

使用步骤：

1. 打开你想处理的网页。
2. 打开 localAI。
3. 点击“当前网页”。
4. 选择总结、问答、待办或笔记。
5. 如果是网页问答，在输入框中补充具体问题。

注意事项：

- 网页问答只基于当前页面正文回答。
- 如果页面内容无法读取，localAI 会提示读取失败。
- 如果页面正文没有足够信息，localAI 会说明缺少什么，而不是编造答案。

## 知识库功能

知识库用于保存你导入的本地资料，并在问答时作为优先事实来源。适合放入项目文档、产品说明、会议纪要、个人资料、规范文档、研究资料等文本内容。

知识库是 localAI 获取资料的主要方式之一。localAI 不会去互联网上搜索资料，也不会自动读取没有导入或没有打开的外部内容。导入知识库的文件越完整、越清晰，localAI 基于这些资料回答时就越可靠。

主要能力包括：

- 导入知识文件：把本地文本资料加入知识库。
- 自动切分和索引：localAI 会把资料拆成片段并建立本地索引。
- 知识库问答：当问题与资料相关时，localAI 会优先依据知识库回答。
- 引用片段查看：回答下方展示来源，点击可以查看原始片段。
- 多知识空间：可以创建不同知识空间，用于区分不同项目或主题。
- 删除知识文件：删除不再需要的资料。
- 清空知识库：移除当前知识空间里的资料。
- 重建索引：当索引异常或资料更新后，可以重新建立索引。

使用步骤：

1. 点击“知识库”。
2. 选择当前知识空间，或新建一个知识空间。
3. 点击导入入口，选择要导入的文件。
4. 等待导入和索引完成。
5. 在输入框中提问，例如“根据知识库总结一下项目目标”。
6. 查看回答下方的引用来源，必要时点击来源查看片段。

知识库适合的问题：

- “根据知识库回答这个项目的核心功能”
- “从文档里提取风险点”
- “这个方案里有哪些待办”
- “帮我对比文档里的几个选项”

## 个人记忆功能

个人记忆用于保存与你有关的长期信息，例如偏好、身份信息、项目约定、常用工作方式和任务状态。它不是普通文档库，更适合保存简短、稳定、可复用的信息。

适合保存为个人记忆的内容包括：

- 你的称呼、身份、职业或角色。
- 你的沟通偏好和回答风格偏好。
- 你长期维护的项目、技术栈或工作习惯。
- 某些反复需要用到的个人事实。
- 当前项目中的长期约定。

可以用自然语言让 localAI 记住信息，例如：

- “记住：我喜欢简洁直接的回答。”
- “记住：我的项目叫 localAI。”
- “记住：我倾向于先做结构化计划，再执行代码修改。”

也可以让 localAI 删除相关记忆，例如：

- “删除记忆：回答风格”
- “忘记关于某个项目的记忆”

询问个人记忆时，可以这样问：

- “你记得我的偏好吗？”
- “我是谁？”
- “我现在主要在做什么项目？”
- “你知道我什么？”

回答规则：

- 当问题与你本人、偏好、项目、习惯或已保存事实相关时，localAI 会优先使用个人记忆。
- 个人记忆里的第一人称来自你的原话，回答时会转换成面向你的自然表达。
- 个人记忆的内部分类不会作为正文内容展示。

## 文本处理能力

localAI 支持常见文本处理任务。你可以直接把文本粘贴到输入框，并说明目标。

支持的任务包括：

- 总结：压缩长文本，提炼重点。
- 翻译：中英文互译。
- 改写：让表达更自然、更正式或更清晰。
- 写作：起草邮件、文案、说明、计划或清单。
- 提取待办：从文本中提取任务、时间、负责人和下一步。
- 格式转换：把内容整理成 JSON、Markdown、表格或列表。

示例：

- “把下面内容总结成 5 条要点：……”
- “翻译成英文：……”
- “把这段话改得更自然：……”
- “把下面记录整理成 Markdown 表格：……”
- “从这段会议纪要里提取待办：……”

## 确定性计算与整理

对于适合程序处理的任务，localAI 会优先使用确定性执行结果，避免模型重新计算导致错误。

支持的确定性任务包括：

- 数值计算：求和、平均、百分比、加减乘除等。
- 排序：按数字、大小、顺序进行排序。
- 格式转换：把结构化文本转换成 JSON、表格或列表。

示例：

- “计算 128 + 256”
- “把 3、9、1、5 从小到大排序”
- “把下面数据转成 JSON”

## 数据导出与导入

设置中提供数据管理能力。

导出备份：

- 用于完整恢复 localAI 的本地数据。
- 包含本地 IndexedDB 中保存的会话、知识库、个人记忆等数据。
- 适合迁移浏览器环境、备份当前状态或调试前保存现场。

导出通用数据：

- 使用 JSONL 格式。
- 主要保留知识库文本片段和个人记忆文本。
- 不包含本地 embedding 数据。
- 适合给其他 AI 工具、RAG 工具或数据处理流程复用。

导入数据：

- 可以从备份文件恢复 localAI 数据。
- 导入会覆盖当前本地数据。
- 导入前应确认文件来源可靠，并确认当前数据已经备份。

## 侧边栏和全屏模式

localAI 可以在不同界面形态中使用：

- Popup：适合快速提问和轻量操作。
- Side panel：适合边浏览网页边提问或总结页面。
- Tab 全屏模式：适合长对话、知识库问答、整理文档和集中工作。

如果 Chrome 侧边栏太窄，可以拖动侧边栏左侧边缘向左拉宽。localAI 会在侧边栏模式下尽量使用适合窄宽度的布局。

## 模型与可用性

localAI 依赖 Chrome 内置 AI 能力，主要使用 Gemini Nano。本地模型能力是否可用取决于 Chrome 版本、实验性功能开关、模型下载状态和浏览器权限。

这个模型在 localAI 中不是联网搜索模型。它不会访问互联网，也不会主动查询搜索引擎、网页、新闻、股票、天气或其他在线服务。localAI 的回答来自用户已经提供给它的信息，并基于这些信息进行语言理解、推理、整理和生成。

如果提示模型不可用，可以检查：

- Chrome 是否支持内置 AI API。
- 相关 Chrome flags 是否已开启。
- 本地模型是否已经下载完成。
- 扩展是否有当前页面读取权限。
- 当前功能是否需要特定 API，例如 Summarizer、Translator、Writer 或 Rewriter。

## 常见问题

### 为什么回答里有引用来源？

当 localAI 使用了知识库或个人记忆时，会在回答下方显示来源，方便你确认回答依据。知识库来源通常会在正文中用编号标注，个人记忆通常只在下方显示来源标签。

### 为什么网页内容无法读取？

可能是当前页面禁止扩展读取、页面内容为空、页面还没有加载完成，或当前标签页不是普通网页。可以刷新页面后重试，或把网页正文复制到输入框中处理。

### 为什么模型不可用？

可能是 Chrome 版本不支持、内置 AI API 没开启、模型还在下载、设备不满足条件，或浏览器暂时没有开放对应能力。

### localAI 会联网搜索吗？

不会。localAI 不是互联网搜索工具，也不会主动访问在线网页或外部数据库。它只能基于你提供的信息回答，包括当前输入、当前网页正文、导入的知识库、个人记忆和最近会话上下文。如果问题需要最新信息或外部资料，需要先把相关内容提供给 localAI。

### 知识库和个人记忆有什么区别？

知识库适合保存较长的文档和资料，回答时可以查看引用片段。个人记忆适合保存简短、稳定、与你有关的事实和偏好。

### 什么时候应该使用全屏模式？

当你需要处理长文档、连续追问、查看历史对话、管理知识库或进行较长时间的整理工作时，建议使用全屏 Tab 模式。
