# localAI 手动验收清单

本清单用于每次发布前做最小端到端验收。localAI 不联网，也不是搜索引擎；所有回答都应基于用户输入、已导入知识、已保存记忆、当前网页正文和 Chrome 本地模型生成。

## 前置条件

- 使用支持 Chrome Built-in AI API 的 Chrome 版本，并确认本地模型已下载或可下载。
- 执行 `npm run build`，在 Chrome 扩展管理页加载 `dist/`。
- 准备一个 `.md` 或 `.txt` 文件，内容包含一个可检索的唯一短语，例如 `localAI-acceptance-token`。
- 打开一个普通网页，用于验证当前网页助手。

## popup

- 打开扩展 popup，确认首页可见，输入框、知识库、个人记忆、当前网页和更多操作入口可用。
- 导入准备好的知识文件，提问包含 `localAI-acceptance-token` 的问题，确认回答下方出现知识库引用 chip，点击 chip 可展开引用片段。
- 输入“记住：我喜欢用结构化计划解决问题”，再提问“我偏好怎样解决问题？”，确认回答使用二人称表达，并且正文不展示内部记忆类型元数据。
- 输入“计算 12 + 30 / 3”，确认任务卡片显示意图、计划、状态和工具；展开确定性执行详情后能看到原始输入、解析结果和最终结果。
- 在输入框中输入一段文本，点击更多操作中的摘要、翻译、写作、润色，确认任务会产生回答并保存历史。

## side panel

- 从 popup 或扩展入口打开侧边栏，确认窄宽度下任务卡片、知识库浮层、个人记忆浮层不超出边界。
- 执行一次计算或格式转换，确认计划步骤状态可见，pending、ready、completed、failed、blocked 的样式不会造成文本重叠。
- 在任务运行时关闭 popup，只保留侧边栏或重新打开扩展，确认任务状态能从历史会话恢复。

## 新标签页

- 打开新标签页模式，确认左侧历史栏展开和收起均可选择会话，任务卡片宽度与主内容区对齐。
- 执行一次知识库问答，确认引用 chip 可点击展开，消息操作按钮支持复制、下载 Word、重新回答。
- 执行一次当前网页摘要或问答，确认网页正文被读取，回答不编造网页外信息。

## 失败与恢复

- 临时关闭 Chrome Built-in AI API 或使用不支持的 Chrome 环境触发一次失败任务。
- 确认失败任务卡片展示“继续任务”“复制错误”“查看任务详情”。
- 点击“复制错误”，确认错误文本进入系统剪贴板。
- 恢复 API 可用性后点击“继续任务”，确认任务重新进入 queued/checking/running，并最终 completed 或给出新的失败原因。

## 回归边界

- 复制功能只依赖 Clipboard API；不再使用 `document.execCommand`。
- popup、side panel、新标签页三种 surface 的基础聊天、历史切换、知识库导入、记忆管理和设置导出入口都能打开。
